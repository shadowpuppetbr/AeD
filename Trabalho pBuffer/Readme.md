## Desafio

Não é permitido criar variáveis, apenas um buffer de memória (`void *pBuffer`).  
Com isso, vocês terão que fazer o trabalho que o Sistema Operacional normalmente faz para vocês ao organizar a memória.

---

## Regras

✅ **Permitido:**
- Apenas ponteiros.
- Todos os dados do programa devem ser guardados dentro do `pBuffer`.

❌ **Proibido:**
- Declarar variáveis (ex.: `int c; char a; int v[10];`)
- Usar `struct` em todo o programa.
- Passar variáveis como parâmetro de função (ex.: `void Funcao(int parametro)`).
