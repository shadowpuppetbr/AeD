# trabalho prático 3

Nome: Gustavo dos Santos Leon
Turma: M2

---

**Descrição**
Dada a raiz de uma árvore de busca binária, retorne uma árvore de busca binária balanceada com os mesmos valores de nós. Se houver mais de uma resposta, retorne qualquer uma delas.

---

**Exemplos**
Input: root = [1,null,2,null,3,null,4,null,null]
Output: [2,1,3,null,null,null,4]
Explanation: This is not the only correct answer, [3,1,4,null,2] is also correct.

**Principais dificuldades**
Demorei um pouco para achar a solução, porem graças a insistência não consultei nenhuma ajuda de IA, ou material que entregasse a resposta.
O professor pediu para depois de solucionar por conta própria implementar uma solução do editorial, porem não consegui implementar a versão mais complexa do editorial devido a ter demorado.
